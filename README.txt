PUM'S BIRTHDAY WISHLIST WEBSITE ♡

WHAT'S INSIDE
- app.py: the Python + Flask website
- static/yuki.jpeg: your actual Yuki photo
- static/clothes.jpeg: your clothes inspiration photo
- static/flowers_chocolates.jpeg: your flowers and chocolates photo

RUN IT ON YOUR LAPTOP
1. Install Python.
2. Open Terminal / Command Prompt in this folder.
3. Run: pip install flask
4. Run: python app.py
5. Open http://127.0.0.1:5000 in your browser.

The website saves his button choices in birthday_choices.json.

SHARING IT WITH YOUR BOYFRIEND
This version runs locally on your laptop. For him to open it from anywhere,
the website needs to be deployed to a hosting service. Keep this folder together
when deploying so the photos load correctly.

To stop the local server, press Ctrl+C in the terminal.
